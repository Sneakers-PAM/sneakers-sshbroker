# sneakers-sshbroker 🐹

> 🧭 Sneakers SSH broker: brokered SSH sessions without revealing keys

## 📦 Install

```bash
go get github.com/Sneakers-PAM/sneakers-sshbroker
```

## 🛠 Develop

```bash
task build    # go build ./...
task test     # go test ./...
task lint     # gofmt check + golangci-lint + yamllint
task license  # check Apache-2.0 headers (golic)
```
